# 🍊 Swiggy Sales & Analytics Dashboard — Excel

An interactive **Swiggy Sales & Analytics Dashboard built entirely in Microsoft Excel** to analyze sales, orders, ratings, food categories, and geographic performance.

## 📊 Dashboard Preview

![Swiggy Sales & Analytics Dashboard](screenshots/Swiggy_Dashboard.png)

---

## 🎯 Project Overview

This project transforms Swiggy-related sales data into an interactive Excel dashboard for exploring business performance and identifying important trends.

The dashboard provides insights into:

- Sales and order performance
- Average order value
- Customer ratings
- Food-type performance
- State-wise sales
- Top-performing cities
- Monthly, daily, and weekly sales trends
- Quarterly sales, ratings, and orders
